# Architecture Decision Records (ADR)

This directory contains the Architecture Decision Records for the `laptop-bootstrap` project.

An ADR captures a significant architectural decision — the context that triggered it, the decision itself, the alternatives considered, and the consequences.

## Format

Each ADR follows the [MADR](https://adr.github.io/madr/) lightweight template:

- **Status**: proposed, accepted, deprecated, superseded
- **Context**: what problem are we solving, what constraints apply
- **Decision**: the approach chosen, in one sentence plus detail
- **Consequences**: positive, negative, neutral outcomes
- **Alternatives considered**: other options and why they were rejected

## Naming

`NNNN-short-slug.md` where `NNNN` is a zero-padded sequential number.
